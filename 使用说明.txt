桌面外设电量 · 使用说明
================================

启动
----
双击桌面“桌面外设电量”快捷方式，或从开始菜单启动。
请使用桌面或开始菜单快捷方式启动；直接双击安装目录里的 exe 可能会看到一个黑色控制台窗口。
程序启动后常驻任务栏通知区（系统托盘），桌面上只显示一个透明背景的虚拟形象。

界面
----
· 头像右下角徽章：优先显示首个有电量的鼠标，没有鼠标时显示首个有电量的外设。
· 只显示当前处于连接状态的设备；断开后会自动从列表隐藏。
· 桌面形象：黑发墨镜少女贴纸，保留原图白色描边。
· 左键单击头像：展开/收起云朵气泡。悬停不会自动展开。
· 左键按住头像时保持轻微上下压缩，松开后回弹。
· 右键头像：打开 50% 圆角设置卡片（大小滑块、开机启动、隐藏挂件、立即刷新、退出）。
· 按住头像拖动：可放在桌面任意位置，位置会自动保存。
· 拖到屏幕边缘（距离 14px 内松手）：挂件收进屏幕，只在边缘留下一个小标签。
· 点击边缘小标签：挂件从屏幕边缘滑出，恢复完整头像和电量气泡。
· 右键任务栏通知区图标 → 设置...：打开同一个设置卡片。
· 设置卡片内拖动大小滑块：50%–300%，100% = 原来的“大”；调整后立即生效并保存。
· 300% 可能超出屏幕高度，建议按实际桌面大小调小。

气泡面板
--------
电量面板是白色椭圆气泡，深海军蓝粗描边，右侧两个思考小圆点指向头像；当前气泡尺寸约为原版的 50%。
面板会按设备数量自动增减行数；没有发现支持电量的设备时，会显示“未发现支持电量读取的外设”。

支持范围
--------
1. MCHOSE HUB 已识别的设备：读取 HUB 本地缓存里的电量，不限键盘/鼠标型号；
   只要 HUB 能识别、当前已连接并上报电量，就会动态显示。
2. 标准 BLE Battery Service 设备：读取 GATT Battery Level（0x2A19），例如部分蓝牙键盘/鼠标。
3. 有线键盘没有电池时显示“不显示电量”属正常；无线设备若显示“未检测到电量”，请确认厂商驱动/HUB 已读取。
4. 2.4G 接收器已连接、但 HUB 还没上报电量的键盘（例如 K87 V3 2.4G）会显示“已连接 · 未读取电量”，不再直接隐藏。

不能保证所有外设都支持：罗技 G HUB、雷蛇 Synapse 等厂商私有协议需要单独适配；Windows 也不提供统一的厂商无关电量接口。

数据来源
--------
MCHOSE HUB 本地缓存：
%APPDATA%\MCHOSEHUB\Local Storage\leveldb
以及 Windows BLE GATT Battery Service。
因此需要 MCHOSE HUB 正在运行（MCHOSE 设备），并且设备已连接、电量已上报。

托盘图标找不到？
--------------
Windows 11 默认把新图标放进通知区溢出菜单（任务栏右下角 ^）。
打开 ^，把“桌面外设电量”图标拖到任务栏上即可固定显示。

卸载
----
右键托盘图标 → 退出。
删除安装目录：%LOCALAPPDATA%\Programs\MCHOSEBatteryWidget
删除桌面和开始菜单快捷方式即可。

故障排查
--------
查看日志：%APPDATA%\MCHOSEBatteryWidget\error.log
如果打开后没有数据：先启动 MCHOSE HUB，确认设备已连接；蓝牙设备确认已配对并在系统中出现，再右键托盘图标选择“立即刷新”。

版本
----
桌面外设电量 1.6.4


说明：从 v1.6.4 起，程序会优先读取 MCHOSE HUB 实时界面中的电量；如果 HUB 未运行，则回退到 HUB 缓存和标准 BLE。
